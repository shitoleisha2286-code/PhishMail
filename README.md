# 🛡️ PhishMail — Email Security Analyzer

**Know What's in Your Inbox.**

🚀 **[Try PhishMail Live](https://phishmail-jhukuhnsahsmvjrncjofx2.streamlit.app/)**

PhishMail is a Python-based tool that analyzes email content for suspicious phrases and potentially risky URLs to identify possible phishing indicators.

## Features
- Detects suspicious phrases in emails.
- Identifies potentially risky URL patterns.
- Calculates a rule-based risk score.
- Classifies emails as Low, Medium, or High risk.
- Provides safety recommendations.

## Tech Stack
- Python
- Streamlit

## Run Locally

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```
